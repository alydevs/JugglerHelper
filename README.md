JugglerHelper
=============

A King Of The Bridge mod to help track progress on Juggler achievement by highlighting the last-moved piece and notifying in the log when Juggler is lost

Installation
------------

1. Get MelonLoader.Installer.exe: https://github.com/LavaGang/MelonLoader.Installer/releases/latest/download/MelonLoader.Installer.exe
2. Use it to install MelonLoader on King of the Bridge (tested MelonLoader v0.7.3)
3. Extract JugglerHelper.zip to your King of the Bridge installation folder. It'll put the file JugglerHelper.dll into Mods/
4. Run the game
